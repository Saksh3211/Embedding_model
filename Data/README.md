# Training Corpus

Each `.txt` file in this folder contains plain-text example sentences, grouped by topic in the filename. These synthetic examples are for learning and testing, not a large or production-quality corpus.

For meaningful results, replace or expand them with text from the domain you care about. Keep training text in UTF-8 format. The corpus files intentionally contain no topic headings, so those labels do not become training tokens.
